# Module 4: The Control Center 💻🎛️

This is the final step! We have built our hardware and connected it to the internet. Now, we are going to build a custom website (Dashboard) that you can open on your computer to monitor your Bedroom or Farm.

## 🛠️ What You Need
* A computer with a web browser (Chrome, Edge, Safari).
* Your Pico W powered on and connected to WiFi from Module 3.

## 💻 Your Mission
1. Download the `index.html` file from this folder.
2. Double-click it to open it in your web browser.
3. Type in your Adafruit IO username to link the website to your live data.
4. Click the "Turn On Light" button on the website and watch the physical LED on your desk turn on!

## 🚀 The Hacker Challenge
Open the `index.html` file in a text editor like Notepad. Can you find where the title of the website is written and change it to "My Awesome Smart Bedroom" or "Super Tech Farm"?
