# 🎨 AI Theme Generator Guide

Welcome to the Hacker Challenge! You don't need to be a CSS expert to make your dashboard look amazing. By using the prompts below, you can ask an AI assistant to write the code for you!

---

## 🛠️ The Custom Theme Template

Want to design a completely unique theme? Copy the template below, fill in your choices inside the brackets `[ ]`, and send it to your AI assistant!

> Please redesign my index.html dashboard with a custom theme based on my choices below!
>
> 1. My Favorite Theme/Character: [ e.g., Iron Man / Frozen / Harry Potter ]
> 2. Background Mood: [ e.g., High-Tech Red / Icy Blue / Magical Castle Dark ]
> 3. Button & Highlight Style: [ e.g., Gold / Snow White / Spell-Casting Green ]
> 4. Title Name: [ e.g., Stark Tower / Elsa's Ice Palace / Hogwarts Monitor ]
>
> Instructions:
> - Automatically select matching CSS colors that look awesome together.
> - Choose fun matching emojis for Temperature, Humidity, Light Level, and Motion.
> - Return the full updated index.html code so I can paste it directly into my file!

## 📋 How to Apply Your AI Theme

Once you have picked your favorite theme prompt from the list above, follow these steps to update your dashboard:

1. **Ask the AI:** Highlight and **Copy** (`Ctrl + C` or `Cmd + C`) your chosen theme prompt. **Paste** (`Ctrl + V` or `Cmd + V`) it into your AI assistant and hit send!
2. **Copy the New Code:** The AI will act as your co-pilot and generate a brand new `index.html` file for you. Look for the "Copy code" button in the AI's response and click it.
3. **Replace Your Old Code:** Open your current `index.html` file in your code editor. Highlight **ALL** the code inside it, delete it, and **Paste** the new code from the AI. 
4. **Save and Refresh:** Save your file (`Ctrl + S` or `Cmd + S`). Go back to your web browser and hit **Refresh** to see your awesome new dashboard theme in action!
