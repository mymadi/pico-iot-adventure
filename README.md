# 🚀 Pico IoT Adventure: Primary School Course

Welcome to the **Pico IoT Adventure** repository! This hands-on primary school course guides students through building a complete Internet of Things (IoT) system using the **Raspberry Pi Pico W** and **CircuitPython**.

Students will learn to bridge physical electronic hardware with modern browser-based web dashboards using **Adafruit IO** and **MQTT**.

---

## 🌟 Learning Themes

Students can choose between two fun real-world applications to build throughout the course:

* 🛏️ **Theme 1: The Smart Bedroom**  
  Build an automated nightlight, smart morning window curtains, and a security monitor.
* 🌾 **Theme 6: The Mini Smart Farm**  
  Build an automated greenhouse grow light, a smart sunshade deployer, and a crop security system.

---

## 🛠️ Required Hardware List

* **Microcontroller:** Raspberry Pi Pico W
* **Sensors:**
  * LDR (Light Dependent Resistor)
  * DHT22 (Temperature & Humidity)
  * PIR Sensor (Motion Detection)
* **Actuators:**
  * LED + Resistor
  * SG90 Micro Servo Motor
* **Accessories:** Breadboard, Jumper Wires, Micro-USB Cable, Cardboard Craft Materials

## 🧰 Software Requirements

1. **[Thonny IDE](https://thonny.org/):** For editing and running CircuitPython code.
2. **[CircuitPython UF2](https://circuitpython.org/board/raspberry_pi_pico_w/):** Installed on the Raspberry Pi Pico W.
3. **Adafruit IO Account:** Free MQTT broker for cloud data storage.

---

## 🚀 Quick Setup Instructions

1. Clone or download this repository.
2. Open **Thonny IDE** and set the interpreter to **CircuitPython (Generic)**.
3. Plug in your Raspberry Pi Pico W and start with **[Module 1](./Module-1-Hello-Brain)**!
